# Security policy

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/cagojeiger/notegate/security/advisories/new), rather than a public issue. Include the affected release, reproduction steps, and impact; do not include production credentials or private documents.

Security fixes target the latest release. Older releases do not have a separate maintenance branch. Repository checks and their documented exceptions are described in the [development guide](docs/development.md#보안과-의존성-관리).
